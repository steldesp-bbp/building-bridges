Η δέσμευσή μου προς εσας

Να είμαι καθ' όλα παρών μαζί σας και για εσάς, ό,τι κι αν βιώνετε στις συνεδρίες μας· είτε αυτό είναι η ανάγκη για στήριξη απέναντι στις δυσκολίες της ζωής, είτε μια ευκαιρία να νιώσετε ευγνωμοσύνη όταν αυτή ρέει αβίαστα. Μέλημα μου είναι να είμαι αξιόπιστος, συστηματικός και συνεπής, φροντίζοντας οι συνεδρίες μας να κυλούν όσο το δυνατόν πιο ομαλά, αντιμετωπίζοντας σας πάντα με σεβασμό.

Να είστε διατεθειμέν@ να εξερευνήσετε τα βιώματά σας (συναισθήματα, σκέψεις, συμπεριφορές, σωματικές αισθήσεις) όσο πιο ειλικρινά και ανοιχτά μπορείτε, βοηθώντας έτσι τη θεραπευτική διαδικασία και την επίτευξη των στόχων σας μέσα σε αυτήν.

Πώς δουλεύω

Ξεκινάμε με μια εισαγωγική συνάντηση διάρκειας περίπου 60 λεπτών. Σε αυτήν μπορούμε να διερευνήσουμε τι ελπίζετε να αποκομίσετε από τη θεραπεία και αν νιώθετε άνετα να δουλέψουμε μαζί.

Αν αποφασίσουμε να προχωρήσουμε, ορίζουμε μια σταθερή μέρα και ώρα συνάντησης την εβδομάδα, με τις επόμενες συνεδρίες να διαρκούν 45-50 λεπτά.

Α. Βραχυπρόθεσμη Συμφωνία (3-6 μήνες / 8-20 συνεδρίες)

Αυτή η επιλογή έχει νόημα αν σας απασχολεί ένα συγκεκριμένο ζήτημα που θέλετε να εξετάσετε ή να επιλύσετε και προτιμάτε το πλαίσιο που προσφέρει ένας ξεκάθαρος χρονικός ορίζοντας. Η τελευταία μας συνεδρία θα περιλαμβάνει μια ανασκόπηση της δουλειάς μας, ώστε να αποτιμήσετε την εμπειρία σας και να ενσωματώσετε ό,τι μπορεί να μάθατε μέσα από αυτήν.

Ταυτόχρονα, είναι μια ευκαιρία να πάρετε μια γεύση από τη διαδικασία και τον ρυθμό των συναντήσεων, σε περίπτωση που θελήσετε να συνεχίσετε περαιτέρω.

Β. Μακροχρόνια Σχέση

Αν το νιώθετε σωστό, μπορείτε να επιλέξετε να συνεχίσουμε μαζί σε πιο σταθερή βάση. Η έρευνες δείχνουν ότι αυτό που μετράει περισσότερο στο θεραπευτικό αποτέλεσμα είναι η ποιότητα της σχέσης που θα αναπτυχθεί μεταξύ μας (γνωστή και ως «θεραπευτική συμμαχία»). Όπως είναι φυσικό, οι σχέσεις βαθαίνουν με τον χρόνο. Κάποια πλεονεκτήματα που βλέπω σε αυτή την επιλογή είναι:

  • Δεν υπάρχει πλέον πίεση να «διορθωθούν» τα πράγματα· μπορείτε να αφεθείτε στη διαδικασία και να εμπιστευτείτε ότι θα πάρει όσο χρόνο χρειάζεται. Στο δικό μου θεραπευτικό ταξίδι, το να γνωρίζω ότι υπάρχει ένα σταθερό ραντεβού στο οποίο μπορώ να επεξεργάζομαι τις εμπειρίες μου, με ξελάφρυνε από τα «προβλήματά» μου, αφήνοντάς περισσότερο χώρο να βιώνω το παρόν.
  • Ο τρόπος που σχετιζόμαστε με τους άλλους πήρε χρόνια να διαμορφωθεί, κι έτσι αναπόφευκτα, δεν είναι εύκολο να αλλάξει από τη μια μέρα στην άλλη. Η δέσμευση σε μακροχρόνια θεραπεία το κάνει πιο πιθανό να αντιμετωπίσουμε παλιούς «δαίμονες» που κατά κάποιον τρόπο επιστρέφουν και μας «στοιχειώνουν» στο παρόν. Η (επανα)γνωριμία με τα πρώιμα μοτίβα μας μπορεί να είναι μια ευκαιρία να συμφιλιωθούμε με λιγότερο αποδεκτές πλευρές του εαυτού, και να μας οδηγήσει σε μια νέα αίσθηση ελευθερίας.

Η μακροχρόνια θεραπεία είναι μια διεργασία ανοιχτού χρονικού ορίζοντα, επομένως εσείς αποφασίζετε πότε θέλετε να ολοκληρώσετε, ή να κάνετε ένα διάλλειμα, για όσο διάστημα κρίνετε χρήσιμο, και για οποιονδήποτε λόγο. Η πόρτα είναι πάντα ανοιχτή να επιστρέψετε.

Δεν υπάρχει ένα μοντέλο που να δουλεύει το ίδιο καλά για όλους. Εάν οι παραπάνω επιλογές δε σας εξυπηρετούν, είμαι ανοιχτός στο διάλογο και θα χαρώ να βρούμε έναν εναλλακτικό τρόπο δουλειάς ο οποίος θα ανταποκρίνεται στις ανάγκες σας, αρκεί να νιώθω κι εγώ άνετα με αυτόν.

Εμπιστευτικότητα, Ασφάλεια & Εποπτεία

Η θεραπευτική διαδικασία είναι απολύτως εμπιστευτική. Ό,τι λέμε στις συναντήσεις μας μένει μέσα στα όρια της θεραπευτικής σχέσης. Το μόνο πρόσωπο με το οποίο ενδέχεται να μοιραστώ πληροφορίες από τις συνεδρίες μας είναι ο επόπτης μου, βελτιώνοντας έτσι την ποιότητα των υπηρεσιών μου προς εσάς. Ακόμη και τότε, δεν θα αποκαλύψω το επώνυμό σας ή άλλα περιττά στοιχεία ταυτότητας.

Σε σπάνιες περιπτώσεις μπορεί να χρειαστεί να άρω την εμπιστευτικότητα (για παράδειγμα, όταν κινδυνεύει η δική σας ζωή ή ενός άλλου ανθρώπου, ή αν υπάρχουν σοβαρά ζητήματα προστασίας ανηλίκων). Παρ' όλα αυτά, θα προσπαθώ πάντα να το κουβεντιάσω πρώτα μαζί σας, ελπίζοντας να γίνουν κατανοητοί οι λόγοι και να σας βρω σύμφων@.

Ως προς τις online συνεδρίες, λαμβάνω μέτρα προστασίας δεδομένων. Ωστόσο, θα χρησιμοποιούμε λογισμικό τρίτων (όπως Zoom, Signal, Viber, WhatsApp) και δεν φέρω καμία ευθύνη για τυχόν διαρροή από δική τους πλευρά.

Όπως εγώ τηρώ την εμπιστευτικότητα για τις συνεδρίες μας, ζητώ το ίδιο και από εσάς, μην κοινοποιώντας οποιοδήποτε υλικό στο διαδύκτιο (εννοείται ότι μπορείτε να μοιραστείτε την εμπειρία σας με δικούς σας ανθρώπους).
